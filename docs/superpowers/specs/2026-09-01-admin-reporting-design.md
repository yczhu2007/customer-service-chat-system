# 管理端运营报表设计

**日期：** 2026-09-01  
**范围：** 在管理员工作台增加只读“报表”页签，提供会话、客服接待、首响、会话时长、满意度与工单的聚合分析。

## 目标与边界

- 在 `/admin` 内新增“报表”页签，不新增路由、角色或权限记录。
- 报表只对 `ADMIN` 开放，沿用现有 `chat:admin:dashboard:view` 权限。
- 一个全局日期范围作用于所有指标；默认最近 30 个自然日（含当天）。趋势图可切换按日或按周聚合。
- 后端直接聚合数据库数据，前端不得分页拉取会话、消息或工单明细后自行统计。
- `echarts@^6.1.0` 仅用于前端渲染，不引入 `vue-echarts` 或其他图表包装库。
- 不新增数据库表、字段和迁移；不改变用户端、客服端及现有管理端页面。

## 指标口径

| 指标 | 口径 | 展示 |
|---|---|---|
| 会话量趋势 | `chat_session.create_time` 位于日期范围内；`DAY` 按自然日，`WEEK` 按周一开始的自然周分桶，补齐无数据桶 | 折线图 |
| 客服接待量排行 | 日期范围内创建且 `agent_id` 非空的会话，按会话当前/最终负责客服分组；最多返回前 10 名 | 横向柱状图 |
| 平均首响时长 | 有客服回复的会话中，第一条未撤回、`sender_role='AGENT'` 的消息时间减去会话创建时间；无有效样本返回 `null` | KPI 卡片 |
| 会话时长分布 | 已结束会话的 `end_time - create_time`，分为 `0–5`、`5–15`、`15–30`、`30–60`、`60+` 分钟 | 柱状图 |
| 满意度 | 评价创建时间位于日期范围内；低分为 1–2 星，低分占比为低分数/评分总数；无评分时均分与占比返回 `null` | KPI + 环形图 |
| 工单状态分布 | 创建时间位于日期范围内的 `support_ticket`，按四种既有状态聚合，缺失状态补 0 | 环形图 |

客服转接后的历史接待归属不在本期统计：接待量只使用 `chat_session.agent_id`，与现有会话管理负责人一致。首响以任意客服发送的第一条有效消息为准，避免转接场景漏计。

## 后端设计

新增 `AdminReportQueryDTO`、`AdminReportOverviewVO` 与子指标 VO，所有查询共用 `from`、`to`、`granularity`。提供一个总览接口：

```http
GET /chat/admin/reports/overview?from=2026-08-01T00:00:00&to=2026-09-01T00:00:00&granularity=DAY
```

服务层负责日期默认值、范围校验、`DAY/WEEK` 校验和零值补桶；Mapper 层只执行聚合 SQL。`to` 为开区间，默认值为次日零点，避免当天数据被截断。报表 Mapper 独立于现有会话分页和工单筛选接口。

## 前端设计

新增 `AdminReportPanel`，在 `AdminWorkspaceView` 注册“报表”页签。页面依次展示：日期范围与日/周切换、平均首响/满意度均分/低分占比 KPI、会话趋势与客服排行、会话时长分布/满意度/工单状态三张图。

新增通用 `ReportChart` 负责 `echarts.init`、`setOption`、`ResizeObserver` 和 `dispose`。ECharts 实例为普通变量，不能进入 Vue 深度响应式状态。面板只负责一次总览请求、空态/错误态以及 option 转换；无数据时显示“暂无数据”，不得填充虚构数值。

## 错误处理与性能

- `from >= to`、跨度超过 366 天、未知粒度返回参数校验错误。
- 一次请求返回全部图表的聚合数据，避免六个并发 HTTP 请求。
- 最大 366 个日桶或 53 个周桶；图表容器有明确高度并在尺寸变化时重绘。
- 非管理员沿用现有权限拒绝响应；不新增缓存、预计算、导出、下钻或实时推送。

## 验证策略

- 后端：默认范围、日期/粒度校验、日/周补桶、无首响/无评分样本、聚合调用和管理员权限。
- 前端：请求参数、KPI 空态、五类 option、ECharts 初始化/销毁、页签切换和错误提示。
- 回归：全量 Maven 与 Vitest、Vite 生产构建；确认管理仪表盘、工单管理与会话管理不变。
