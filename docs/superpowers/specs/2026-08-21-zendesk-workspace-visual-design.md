# Zendesk 风格工作台视觉设计

## 目标

将 `/frontend/index.html` 的用户端、客服端和管理员端改为紧凑、信息密度高的客服工作台视觉，参考 Zendesk 的信息层级，并统一使用 `stomp-test.html` 的颜色体系。

## 视觉规范

- 页面背景：`#f7f8fa`；内容面板：`#ffffff`；边框：`#e7e9ee` 和 `#d6dae2`。
- 主操作：`#4d6bfe`，悬停：`#3a56e0`；正文：`#181d26`；辅助文字：`#6a7280`。
- 状态仅使用绿色 `#1f8a5f`、红色 `#dc2626` 及其浅色背景；不使用渐变、表情符号或装饰图标。
- 字体：`PingFang SC`、`Microsoft YaHei`、`Noto Sans SC`、system-ui 回退；等宽内容使用 `Cascadia Code`、Consolas 回退。
- 控件统一使用 8px 圆角、细边框、聚焦蓝色描边和 12px-14px 的紧凑字号。

## 布局

- 顶部：白色应用栏，显示产品名和当前工作区操作。
- 客服端：固定左侧视图/会话栏、中央对话区、右侧客户与会话上下文栏。
- 用户端：窄会话栏与中央对话区；排队信息采用列表行，不使用卡片装饰。
- 管理端：水平文字导航、数据表格和简洁的统计列表；统计以数字和状态点表示。

## 约束

- 不改变任何 REST、STOMP、权限、路由或数据字段。
- Vue 界面文件不得含 Emoji；该约束由自动测试守护。
- 保留现有响应式结构，在窄屏时允许横向滚动侧栏/表格，不隐藏业务操作。

## 验收

1. 登录、用户、客服、管理员三类页面均使用同一套色板和控件规则。
2. 所有原 Emoji 被纯文字、状态点或 CSS 色块替代。
3. 前端全量 Vitest 测试、Vite 构建和 Maven 打包通过。
