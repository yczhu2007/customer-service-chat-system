# Vue Chat Workspaces — 手动回归测试清单

## 前置条件

1. 数据库已执行最新 `sql/` 脚本（含 `chat:session:view-own`、`chat:session:metadata:update` 权限）
2. Redis 可用
3. `ADMIN_BOOTSTRAP_PASSWORD` 已设置

## 启动

```bash
# 开发模式（前后端分离）
cd frontend && npm install && npm run dev   # http://localhost:5173
cd .. && .\mvnw.cmd -pl application -am spring-boot:run  # http://localhost:8080

# 生产模式（一体化 JAR）
.\mvnw.cmd -pl application -am clean package -DskipTests
java -jar application/target/*.jar
# 访问 http://localhost:8080/user|agent|admin
```
